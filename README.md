# SJM Linktree

A link-in-bio page for **Sukses Jaya Mandala Tools**, a real tools store that sells on Shopee. It gathers the store's shops and social media into a single link that can be shared easily.

**Live demo:** https://jiovanandrea.github.io/sjm-linktree/

![Screenshot of the SJM Linktree page](screenshot.png)

## Features

- Store profile with logo, name, and a short description
- Buttons linking to two Shopee stores and Instagram
- Hover effect on the buttons
- Single-column layout, limited to 500px wide and centered, so it fits mobile screens
- Custom fonts from Google Fonts (Gelasio)

## Built With

- HTML
- CSS (Flexbox)
- GitHub Pages for hosting

2. Open `index.html` in a browser.
